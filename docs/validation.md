# Validation — การตรวจสอบผลคำนวณ DC Bias

เอกสารนี้อธิบายวิธีคำนวณอ้างอิงอย่างอิสระ (ไม่ได้คัดลอกจาก output ของแอป)
และบันทึกผลการทดสอบจริง

## 1. ค่าอ้างอิงจากการคำนวณมือ

พารามิเตอร์: VCC = 12 V, R1 = 100 kΩ, R2 = 22 kΩ, RC = 2.2 kΩ, RE = 1 kΩ,
β = 100, VBE = 0.70 V

**ขั้นที่ 1 — Thevenin ที่ขา Base**

```
VTH = 12 × 22,000 / (100,000 + 22,000) = 264,000 / 122,000 = 2.163934 V
RTH = (100,000 × 22,000) / 122,000      = 2,200,000,000 / 122,000
    = 18,032.787 Ω = 18.0328 kΩ
```

**ขั้นที่ 2 — กระแส Base**

```
ตัวส่วน = RTH + (β+1)·RE = 18,032.787 + 101 × 1,000 = 119,032.787 Ω
IB = (2.163934 − 0.70) / 119,032.787 = 1.463934 / 119,032.787
   = 1.229858 × 10⁻⁵ A = 12.2986 µA
```

**ขั้นที่ 3 — กระแสและแรงดันที่เหลือ**

```
IC  = 100 × 12.29858 µA = 1.229858 mA
IE  = 101 × 12.29858 µA = 1.242157 mA
VE  = 1.242157 mA × 1 kΩ      = 1.242157 V
VB  = 1.242157 + 0.70          = 1.942157 V
VC  = 12 − (1.229858 mA × 2.2 kΩ) = 12 − 2.705688 = 9.294312 V
VCE = 9.294312 − 1.242157      = 8.052155 V
VBC = 1.942157 − 9.294312      = −7.352155 V
```

**Cross-check อิสระอีกทาง:** `VTH − IB·RTH = 2.163934 − (12.29858 µA × 18.0328 kΩ)`
= 2.163934 − 0.221777 = **1.942157 V** เท่ากับ `VB` ที่คำนวณจาก `VE + VBE` ✓

## 5. ข้อจำกัด

- ผลทั้งหมดอยู่ภายใต้ Forward-Active approximation (β, VBE คงที่)
- ไม่ได้เทียบกับ ngspice หรือการวัดจริง — เป็นการตรวจสอบเชิงสมการ
- ค่าที่ Region = Cutoff/Saturation ถูกส่งกลับตามสมการแต่ติดป้ายว่าเชื่อถือไม่ได้
